# v1.4.0 Release Notes

**Released**: 2026-08-05
**Tag**: `v1.4.0`
**Commit**: `3d45389`
**Author**: Xingyu Wei (single-author route)

## What's new

### Quick Switcher (v1.4.0 highlight)
- Press `Ctrl+Shift+B` (Mac: `Cmd+Shift+B`) on any page to open
- Full-screen popup, 720×480 centered on current window
- Fuzzy search across title / URL / domain / tags / notes
- Smart ranking: exact match 1000 → starts 500 → contains 200 → URL 100 → domain exact 150 → tags 80 → fuzzy 30 → star bonus +5
- Keyboard nav: Up/Down move, Enter open, Ctrl+Enter open in background, Esc close
- Mouse hover switches active item
- Window reuse: focuses existing window instead of opening duplicate

### Internationalization infrastructure
- `_locales/en/messages.json` — English fallback (required by `default_locale: "en"`)
- `_locales/zh_CN/messages.json` — Chinese localization
- Manifest uses `__MSG_extensionName__` / `__MSG_extensionDescription__` placeholders
- `default_locale: "en"` is required by Edge for first publish

### Bug fixes
- **v1.2.0 → v1.3.0 cycle**: `default_locale: "zh_CN"` was rejected by Edge. v1.3.0 added `default_locale: "en"` but no `_locales/` folder → also rejected. v1.4.0 finally includes the proper `_locales/` directory.
- `extensionDescription` in `_locales/en/messages.json` was 195 chars → trimmed to 120 chars to fit Edge 132-char limit.
- `homepage_url` corrected from placeholder `xiuxian-world` to actual `bookmark-matrix` repo.

### Documentation
- `CHANGELOG.md` — Keep-a-Changelog format
- `TRACEABILITY.md` — version index with commit/ZIP/SHA256 mapping
- `docs/privacy.html` — proper HTML (was .md, GitHub Pages doesn't auto-render .md at .html URL)
- `docs/privacy.html` ready for GitHub Pages deployment

### Test coverage
- 211 → 228 (+17 new tests for Quick Switcher)
- All passing in < 1 second total

## Build instructions

To rebuild this version from source:

```bash
# Clone
git clone https://github.com/weixingyu-wxy/bookmark-matrix.git
cd bookmark-matrix
git checkout v1.4.0

# Verify tests
node --test tools/test_*.js

# Build ZIP
python scripts/build_zip.py --src ./src --out ./edge-bookmark-matrix-v1.4.0-src.zip

# Verify ZIP integrity
Get-FileHash ./edge-bookmark-matrix-v1.4.0-src.zip -Algorithm SHA256
# Should match: 55d2c56e3cb969448aea9a7c6295f8367866076d181e2f116db67bb5a9e02f22
```

## Known limitations

- Quick Switcher is keyboard-only on initial open (mouse hover works after first focus)
- No fuzzy match across multiple words in the same query (single-token fuzzy only)
- Window reuse requires at least one tab matching `quickswitcher.html` URL pattern

These are documented for the next version (v1.5.0 candidates).
