## Initial public release

The first version of Bookmark Matrix published to the Edge Add-ons store.

## Features (all 12)

1. **18-category auto-classifier** — 100% test accuracy (73 unit tests)
2. **Tags / Notes / Starred** per bookmark (stored in `chrome.storage.local`)
3. **Full-screen matrix page** (new tab override)
4. **Drag-to-sort categories** (customize order in sidebar)
5. **Statistics** — bar chart, donut chart, timeline, top 10 domains (all SVG)
6. **Health check** — dead link detection (HEAD/GET) + RSS feed validation
7. **Periodic review** — `chrome.alarms` + `chrome.notifications` for dormant bookmarks
8. **Kanban view** — status (inbox/reading/todo/done/archive) + priority (high/med/low)
9. **4 theme presets** — Dark, Light, Solarized, Nord
10. **Smart favicon** — LRU cache + multi-source fallback + base64 inline display
11. **Cross-device JSON sync** — import/export with merge/replace modes
12. **Full-text search** — title, URL, domain, tags, notes (case-insensitive)
13. **Optional PWA standalone** — `standalone/` directory, deployable to GitHub Pages

## Privacy

- 100% offline by default
- Zero external API calls
- Zero LLM calls
- Zero telemetry
- Zero dependencies (no jQuery / React / Vue)
- Minimum permissions: `bookmarks`, `storage`, `alarms`, `notifications`, `favicon`
- `host_permissions` (`http://*/*`, `https://*/*`) used **only** for user-triggered health check
