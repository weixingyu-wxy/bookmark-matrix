# 截图清单 — Microsoft Edge Add-ons Store

---

## 📐 通用规格

| 项目 | 要求 |
|------|------|
| 格式 | PNG |
| 尺寸 | **1280x800** (推荐) 或 640x400 |
| 数量 | 1-10 张,推荐 4-6 张 |
| 大小 | < 10 MB / 张 |
| 命名 | 01-xxx.png, 02-xxx.png ... |

## 🎨 设计建议

- **每张图都展示真实内容** (别用空状态)
- **暗色主题** (默认) 显得更专业
- **关键 UI 元素加轻微阴影/边框** 突出
- **避免 PII** (个人邮箱 / 真实收藏夹)
- **可以裁剪** 但保持 16:10 比例

## 🛠️ 截图工具

| 工具 | 平台 | 用法 |
|------|------|------|
| **Win+Shift+S** | Windows | 区域截图,内置 |
| **Snipping Tool** | Windows | 框选截图 |
| **F12 → 截屏** | Edge/Chrome | DevTools 截图 |
| **ShareX** | Windows | 免费,功能多 |
| **Screenshot one** | Mac | Cmd+Shift+4 |

---

## 📝 Edge 浏览器内置截图

1. 打开 Edge → 任何页面
2. **Ctrl+Shift+S** (新版 Edge) 或菜单 "网页截图"
3. 选区域 / 整页
4. 自动复制到剪贴板 → 粘贴到画图 / Photoshop 保存为 PNG

---

## 🖼️ 缩放到 1280x800

如果截图不是 1280x800:
- **画图** (Windows): 重新调整大小 → 像素
- **PowerShell**: 用 `System.Drawing` 缩放
- **Photoshop / GIMP**: 图像 → 图像大小

实际 Edge 商店接受 640x400, 但 1280x800 显示更清晰。

## 📦 上传顺序

1. Partner Center → 你的扩展
2. 左侧 **"Store listing"** (商店资料)
3. 滚到 **"Screenshots"** 区
4. 拖拽 4-6 张图上传
5. 第一张图会作为商店列表的"主图"
6. 选最好看的作为 01
