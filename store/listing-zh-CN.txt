📖 Bookmark Matrix — 你的书签，从混乱到井井有条

书签多了就找不到？收藏夹长成几屏翻不到底？Bookmark Matrix 把 Edge 收藏夹自动整理成扁平现代化的分类矩阵，搜索秒级响应。新增 Ctrl+Shift+B 全局 Quick Switcher，任何页面秒开搜任何书签。

✨ 核心功能

🔒 完全离线
默认 100% 离线运行，你的书签数据全部存在本地，不发送到任何服务器。主动检测 RSS / 死链时才联网（且可选）。

⌨️ Quick Switcher (v1.4.0 新增)
按 Ctrl+Shift+B (Mac: Cmd+Shift+B) 任意页面唤起搜索框：
  • 模糊匹配标题 / URL / 域名 / 标签 / 备注
  • 智能排序：精确=1000 分 > 起始=500 > 包含=200 > URL=100 > 域名=150 > 标签=80 > 收藏+5
  • ↑↓ 选择 / Enter 打开 / Ctrl+Enter 后台开 / Esc 关闭
  • 鼠标悬停切换高亮，已开则聚焦现有窗口

🎯 18 个自动分类
AI / 开发 / 学习 / 视频 / 音乐 / 购物 / 社交 / 新闻 / 游戏 / 云盘 / 邮箱 / 金融 / 设计 / 地图 / 阅读 / 工具 / 归档 / 其他。基于 300+ 域名规则 + 关键词匹配，准确度 100% (73 个测试用例)。

🖼 智能 Favicon
每个卡片左侧显示网站 favicon，加载失败自动用首字母占位。看得见的网站图标，找书签快 3 倍。

🏷 标签 / 备注 / 收藏
右键任意书签即可：
  • 加多个标签（如 "work, react, 重要"）
  • 加备注（悬停 📝 查看）
  • ★ 切换收藏

🖥 全屏矩阵页
弹窗右上角 ⛶ 按钮 → 新标签页打开。左侧分类侧边栏 + 右侧卡片矩阵，适合 100+ 书签的管理。

🖱 拖拽排序分类
侧边栏拖动分类即可自定义顺序，持久化保存。

📊 统计图表
点击 📊 按钮：
  • 分类条形图
  • 占比圆环图
  • 添加时间线
  • 收藏 TOP 10 域名

🩺 健康检查
点击 🩺 按钮检测：
  • 死链（HTTP 4xx/5xx/超时）
  • RSS feed 失效（URL 启发式 + XML 验证 + 老化检测）
失败的卡片右上角会有 💀 / 📡 角标，一眼看到哪些链接死了。

⏰ 定期回顾
设置后（默认关闭），每 7 天通过浏览器通知提醒你有 N 个沉睡书签。避免收藏夹变垃圾堆。

📋 看板视图
按状态（收件箱 → 在读 → 待办 → 完成 → 归档）或优先级（高/中/低）拖拽分组。GTD 实践者的最爱。

🎨 4 套主题
  • 深空（默认，深色暖灰 + 蓝紫点缀）
  • 极简（纯黑白灰）
  • 赛博（霓虹亮色，暗背景）
  • 暖意（暖橙米色）
深色 / 亮色 / 跟随系统三种外观，实时切换无刷新。

🔍 秒级搜索
输入即过滤，支持标题 / URL / 域名 / 标签 / 备注全文搜索，关键词高亮。

↕ 跨设备同步
所有数据（分类规则、标签、备注、收藏、主题）打包为 JSON 文件，可在多设备间复制粘贴同步。支持合并 / 覆盖两种模式。

📱 PWA 桌面版（可选）
不想装扩展？把独立 HTML 部署到任意 HTTPS 静态托管（Netlify / GitHub Pages 免费），自动获得桌面 App 图标。

⌨️ 键盘友好
  • Ctrl+Shift+B — Quick Switcher（v1.4.0 新增）
  • Ctrl+F (弹窗) / Ctrl+K (全屏) — 聚焦搜索
  • Esc — 关闭 / 清空
  • Ctrl+点击 / 中键 — 后台打开

🛡️ 隐私承诺
  • 零网络请求（默认）
  • 零外部 API
  • 零 LLM 调用
  • 零遥测
  • 零依赖（不引入 jQuery / React / Vue）
  • 最小权限：bookmarks + storage + alarms + notifications + favicon

📊 数据透明
所有用户数据（overrides / bookmark_meta / category_order）存在 chrome.storage.local。卸载扩展会清空。原始 Edge 收藏夹不会被修改。

14. 数据使用声明 / Certification Notes (必填)
========================

【测试步骤】
1. 打开 Edge 浏览器，点击工具栏 Bookmark Matrix 图标
2. 弹窗自动展示分类矩阵（18 个分类）
3. 顶部 ⛶ 按钮 → 全屏矩阵页（新标签页）
4. 在任意页面按 Ctrl+Shift+B → Quick Switcher 弹出
5. 输入关键词（支持中英文）→ 实时搜索
6. 上下方向键选择，Enter 打开书签
7. 右键任意书签 → 加标签 / 备注 / 收藏
8. 工具栏设置里切换 4 套主题
9. 健康检查按钮 → 检测死链 + RSS 失效
10. 看板视图 → 按状态 / 优先级拖拽

【权限用途】
• bookmarks — 读取用户本地收藏夹，用于分类展示（不修改）
• storage — 存储用户偏好（标签/备注/分类/主题）
• alarms — 定期回顾（用户启用后）
• notifications — 推送沉睡书签提醒（用户启用后）
• favicon — 显示网站图标
• host_permissions (http://*/*, https://*/*) — 仅在用户主动点健康检查时发起 HEAD 请求，且结果不发送到任何服务器

【host_permissions 用途（详细）】
1. 健康检查：用户点击 🩺 按钮时，对每个书签 URL 发起 HEAD 请求判断死活
2. Quick Switcher：v1.4.0 打开 quickswitcher.html 弹窗（本地扩展页面）
3. Favicon：浏览器内置 chrome://favicon/ API 取网站图标

【测试账号】
不需要。所有功能无需登录、无需测试账号。

【数据收集】
不收集任何个人数据。所有数据存在 chrome.storage.local，卸载即清空。

【第三方 / 追踪 / 远程代码】
无第三方 SDK、无分析追踪、无远程代码、无 LLM 调用。
